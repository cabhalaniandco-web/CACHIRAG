Repository for **Chirag K Jain & Co** tooling and related projects.

## TallyPrime TDL — GSTR-2B portal import buttons

The `tally/` folder contains a **Tally Definition Language (TDL)** add-on for TallyPrime:

- **`tally/GSTR2B_Portal_ImportButtons.tdl`** — adds **Import Configuration** (`Alt+C`) and **Import Selected Vouchers** (`Alt+V`) on the GSTR-2B Reconciliation *Available Only on Portal* voucher list.
- **`tally/README.md`** — load instructions, Developer Mode form-name verification, and how to finish voucher posting.

Load the file in TallyPrime: `F1 (Help) → TDL & Add-On → F4 (Manage Local TDLs)`.
