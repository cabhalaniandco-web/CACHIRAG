# TDL

A focused to-do list. Add tasks, check them off, filter, and edit inline. Everything stays in your browser via `localStorage`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Usage

- Type a task and press **Add** (or Enter)
- Click the circle to mark done / active
- Double-click a task to edit
- Use **All / Active / Done** to filter
- **Clear done** removes completed tasks
